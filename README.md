# KB Booster Auto (Minecraft 1.8.9 / Forge 11.15.1.2318)

Mod apenas cliente que executa o Sprint Reset automaticamente apos acertar jogadores.

- Tecla K: liga/desliga o Sprint Reset (configuravel em Opcoes > Controles > KB Booster Auto)
- Tecla J: abre a tela de configuracoes
- Config salva em `config/kbboosterauto.cfg`

## Compilar
Veja o passo a passo no chat, ou use o GitHub Actions deste repositorio (aba Actions > Build KB Booster Auto).
O JAR fica no artefato `KBBoosterAuto-jar` (arquivo `KBBoosterAuto-1.0.0.jar`).

## Aviso
Muitos servidores proibem automacao de combate. Use em singleplayer, servidores proprios ou onde for permitido.
